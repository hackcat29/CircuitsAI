# Circuits on NEAR

Circuits is an existing multi-chain agent platform. This clean source snapshot is the pre-integration baseline, exported without the private repository’s Git history, environment files, seed data, deployed artifacts, or embedded demo signing keys. Existing Circuits code is baseline work and is not claimed as new NEAR hackathon work.

The NEAR integration will be committed after the `pre-hackathon-baseline` tag. The final README will document the exact diff and reproducible checks. This repository is local and has not been published.
